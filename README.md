#  Simon Says Game

The Simon Says Game is a classic memory-based game where the player must replicate an increasingly complex sequence of colors. Built entirely using HTML, CSS, and JavaScript, this project tests and improves memory through interactive gameplay and smooth visual feedback.

##  Folder Structure

```

SimonSaysGame/
├── simon.html   # Main game interface
├── simon.css    # Styling for the game board and buttons
└── simon.js     # Game logic and event handling

```

##  Features

- Interactive color buttons with sound and animation
- Increasing difficulty with each correct level
- Instant feedback on wrong answers
- Fully responsive and browser-compatible

##  How to Play

1. Open simon.html in any browser.
2. Click on the game board to start.
3. Repeat the color sequence shown by the game.
4. Each correct sequence adds a new step.
5. A wrong click ends the game.

## 🛠 Technologies Used

- HTML5 – Structure of the game interface
- CSS3 – Button design, layout, and animations
- JavaScript (ES6) – Game logic, event listeners, sound integration
